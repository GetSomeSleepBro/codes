# Group A (Unit I and II)

1. Setup a wired LAN using a Layer 2 Switch.
   This includes preparation of cables, testing cables using a line tester, configuring machines using IP addresses, testing using the PING utility, and demonstrating PING packet trace captures using the Wireshark Packet Analyzer Tool.

2. Demonstrate the different types of topologies and transmission media using a Packet Tracer tool.

3. Setup a WAN containing both wired and wireless LAN using the Packet Tracer tool.
   Demonstrate the transfer of a packet from LAN1 (wired LAN) to LAN2 (wireless LAN).

4. Write a program for error detection and correction for 7/8 bit ASCII codes using Hamming Codes or CRC.

5. Write a program to simulate Go-Back-N and Selective Repeat Modes of the Sliding Window Protocol in Peer-to-Peer mode.

<br>

# Group B (Unit III and IV)

6. Write a program to demonstrate Subnetting and find subnet masks.

7. Write a program to implement link-state/Distance Vector routing protocol to find a suitable path for transmission.

8. Use the Packet Tracer tool to configure a 3-router network using one of the following protocols: RIP, OSPF, or BGP.

9. Write a program using TCP sockets for a wired network for the following tasks:  
   a. Say Hello to each other  
   b. File transfer  
   c. Calculator

10. Write a program using UDP sockets to enable file transfer (Script, Text, Audio, and Video - one file each) between two machines.

<br>

# Group C (Unit V and VI)

11. Write a program for DNS lookup.
    Given an IP address as input, it should return the URL and vice-versa.

12. Install and configure a DHCP server and write a program to install the software on a remote machine.

13. Capture packets using Wireshark.
    Write the exact packet capture filter expressions to accomplish the following and save the output in a file:
    1. Capture all TCP traffic to/from Facebook during the time you log in to your Facebook account.
    2. Capture all HTTP traffic to/from Facebook when you log in to your Facebook account.
    3. Write a DISPLAY filter expression to count all TCP packets (captured under item #1) that have the flags SYN, PSH, and RST set. Show the fraction of packets that had each flag set.
    4. Count how many TCP packets you received from/sent to Facebook, and how many of each were also HTTP packets.

14. Study and analyze the performance of HTTP, HTTPS, and FTP protocols using the Packet Tracer tool.

15. Study the SSL protocol by capturing packets using the Wireshark tool while visiting any SSL-secured website (e.g., banking, e-commerce).

16. Illustrate the steps for the implementation of S/MIME email security through Microsoft® Office Outlook.

17. Study the IPsec (ESP and AH) protocol by capturing packets using the Wireshark tool.
