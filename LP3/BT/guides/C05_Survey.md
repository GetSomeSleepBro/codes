# C05 — Survey types of blockchain and real-world use cases

**Syllabus:** Group C #5. **Deliverable:** a survey report, not a Solidity program. `BT/C05_Survey_Report.md` is the prepared study material from Set 2.

## Practical steps

1. Open `BT/C05_Survey_Report.md` and read the four categories: **public, private, consortium and hybrid** blockchains.
2. For each category, list permission model, operator/governance, consensus mechanism, privacy, transparency, and practical examples.
3. Prepare comparison table using the report's chart; do not confuse public Ethereum Proof of Stake with Bitcoin Proof of Work.
4. Select 2–3 use cases and describe the workflow: e.g. Ethereum payments/DeFi, permissioned supply-chain traceability, consortium interbank settlement.
5. Explain real constraints: privacy, scalability, participant trust, cost, security and regulatory compliance.
6. Give an evidence-based conclusion recommending which blockchain type suits a specific case.
7. Cite references such as https://ethereum.org and https://hyperledger-fabric.readthedocs.io rather than reporting speculative live TPS as fixed facts.

**Journal pages:** aim → definitions → classification → comparison → use cases → challenges → conclusion → references.

**No wallet, dataset or transaction is required for this survey.**
