# C02 — Create your own crypto wallet using MetaMask

**Syllabus:** Group C #2. **Files:** none; MetaMask and browser.

1. Open https://metamask.io → install verified browser extension → create new wallet.
2. Choose a strong device password. Store your Secret Recovery Phrase privately OFFLINE. NEVER type or paste it into any lab report, screenshots, chat, GitHub repository, Google form or notebook.
3. MetaMask → select the first Account (typically Account 1). Copy its **public wallet address**. This address is safe to use for test transfers.
4. MetaMask → account menu → **Add account** → create a second account for the same test wallet. Copy second public address. Names/options may differ slightly by MetaMask version.
5. Enable Show test networks and select Sepolia; request faucet test ETH only if available. You can demo the wallet creation without funding.
6. For a live exercise, send a tiny test amount from test Account 1 to test Account 2; approve and inspect both activity tabs and Sepolia Etherscan.
7. Record the account address prefixes (truncate for your journal), network/chain ID, action performed, transaction hash, and fees only if an actual transaction occurred.

**Screenshots:** extension installed; accounts list (public addresses only); Sepolia selected; transaction details if performed. **Never screenshot/export your recovery phrase or private keys.**

**Viva:** wallet vs address, custodial vs self-custodial, public/private key, digital signature, gas, testnet vs mainnet.
