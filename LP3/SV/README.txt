LP-III MACHINE LEARNING PRACTICALS

This ZIP contains four Jupyter notebooks and their required CSV datasets.
Keep each notebook in the same folder as its CSV file.

PRACTICALS
1. Email Spam Classification using KNN and SVM
2. Bank Customer Churn Prediction using a Neural Network
3. Diabetes Prediction using KNN
4. Titanic Survival Prediction

REQUIREMENTS
Python 3, Jupyter Notebook, pandas, numpy, matplotlib, and scikit-learn.

Install the requirements once if they are not already installed:
pip install notebook pandas numpy matplotlib scikit-learn

No dataset downloads are required. All four CSV files are included in this ZIP.
The bank churn neural network uses scikit-learn MLPClassifier; TensorFlow and Keras are not required.

Open each notebook and run its code cells from top to bottom.
