LP-III DAA PRACTICALS - SIX PYTHON PROGRAMS

Files included:
1. A1_Fibonacci_Recursive_and_Non_Recursive.py
2. A2_Huffman_Encoding_Greedy.py
3. A3_Fractional_Knapsack_Greedy.py
4. A4_0_1_Knapsack_Dynamic_Programming.py
5. A5_N_Queens_Backtracking.py
6. Mini_Project_Matrix_Multiplication_Multithreaded.py

HOW TO RUN
1. Extract this ZIP file.
2. Open a terminal or command prompt in the extracted folder.
3. Run a program using: python filename.py

REQUIREMENTS
Python 3.6 or newer. Only the standard library is used.
No pip installation, dataset or internet connection is required.

NOTES
- A1 shows measured times for recursive and iterative Fibonacci for n = 10, 20, 30 and 35.
- A2 prints the original size, encoded size, compression ratio and space saved. The code table size is not included.
- A3 prints the fraction of each item taken.
- A5 asks for the board size n and the position of the first queen. No solution exists for n = 2 or n = 3.
- Mini project:
    Part 1 multiplies two matrices entered by the user using the normal method and using one thread per row.
    Part 2 compares the time of both methods on random square matrices of size 10, 50, 100, 150 and 200.
    In standard Python the threaded method is usually not faster because of the Global Interpreter Lock (GIL).

Each Python file has its sample output as comments at the very bottom. Execution times will vary from computer to computer.
