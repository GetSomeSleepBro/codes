# Group A: Design and Analysis of Algorithms

The syllabus demands 5 regular assignments and 1 mini-project; all six regular assignment variants are included for flexibility. Python files run directly (`python DAA/A01_fibonacci.py`). C++ variants are placed under `DAA/cpp/` and accept interactive input. Outputs intentionally are not embedded in the source or saved as artifacts.

| No. | Topic | Python | C++ |
|---|---|---|---|
| A01 | Recursive/non-recursive Fibonacci | `A01_fibonacci.py` | `cpp/A01_fibonacci.cpp` |
| A02 | Huffman greedy encoding | `A02_huffman.py` | `cpp/A02_huffman.cpp` |
| A03 | Fractional Knapsack | `A03_fractional_knapsack.py` | `cpp/A03_fractional_knapsack.cpp` |
| A04 | 0/1 Knapsack (DP and branch/bound in Python) | `A04_zero_one_knapsack.py` | `cpp/A04_zero_one_knapsack.cpp` |
| A05 | N Queens with first queen already placed | `A05_n_queens_fixed_first.py` | `cpp/A05_n_queens_fixed_first.cpp` |
| A06 | Deterministic vs randomized QuickSort analysis | `A06_quicksort_analysis.py` | `cpp/A06_quicksort_analysis.cpp` |
| MP01 | Naive vs Rabin–Karp string matching (syllabus choice #9) | `MP01_string_matching.py` | – |

### Commands

```bash
python DAA/A01_fibonacci.py --n 12
python DAA/A05_n_queens_fixed_first.py --n 4 --first-col 1
python DAA/MP01_string_matching.py
python verify_cpp.py
```

Do not list QuickSort as a mini-project on the LP3 record: Set 2 had that label, but the university lists it as a regular experiment.
