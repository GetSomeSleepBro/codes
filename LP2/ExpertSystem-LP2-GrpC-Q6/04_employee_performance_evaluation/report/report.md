# Employee Performance Evaluation Expert System Report

## Objective

To build a simple expert system that evaluates employee performance.

## Inputs

- Attendance
- Work quality
- Target completion
- Teamwork

## Knowledge Base

The knowledge base contains rules for classifying performance into simple categories.

## Sample Rules

- If attendance, quality, and targets are high/good, classify as excellent.
- If attendance or quality is poor, classify as needs improvement.
- If teamwork is good and targets are medium or high, classify as good.
- Otherwise, classify as average.

## Conclusion

The system provides a basic rule-based performance evaluation.
