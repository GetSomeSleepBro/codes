# Help Desk Management Expert System Report

## Objective

To build a simple expert system that classifies help-desk tickets.

## Inputs

- Issue type
- Number of users affected
- Business impact

## Knowledge Base

The knowledge base contains ticket priority and routing rules.

## Sample Rules

- If many users are affected, mark the ticket as Priority 1.
- If impact is high, mark the ticket as Priority 1.
- If issue is password, send password reset steps.
- If issue is hardware, assign it to a hardware technician.

## Conclusion

The system helps route support tickets using rule-based reasoning.
