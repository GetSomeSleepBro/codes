# Hospitals And Medical Facilities Expert System Report

## Objective

To build a simple expert system that suggests a care level for a patient.

## Inputs

- Fever level
- Breathing problem
- Pain level
- Injury level

## Knowledge Base

The knowledge base contains simple triage rules for hospital decision support.

## Sample Rules

- If breathing problem is yes, recommend emergency care.
- If injury is major, recommend emergency care.
- If fever is high or pain is severe, recommend priority doctor consultation.
- If injury is minor, recommend first aid and observation.

## Conclusion

The system uses symptoms to suggest a basic hospital action.
