# Airline Scheduling And Cargo Schedules Expert System Report

## Objective

To build a simple expert system that recommends cargo scheduling actions.

## Inputs

- Cargo urgency
- Weather condition
- Flight capacity
- Cargo type

## Knowledge Base

The knowledge base contains rules for safety, priority, capacity, and cargo handling.

## Sample Rules

- If weather is storm, delay and reschedule.
- If cargo is medical or urgency is emergency, assign a priority flight slot.
- If flight capacity is full, move cargo to the next available flight.
- If cargo is fragile, schedule with special handling.

## Conclusion

The system gives a simple scheduling recommendation using rule-based reasoning.
