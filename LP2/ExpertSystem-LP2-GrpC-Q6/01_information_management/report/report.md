# Information Management Expert System Report

## Objective

To build a simple expert system that recommends an information management method.

## Inputs

- Data sensitivity
- Access frequency
- Backup importance
- Sharing requirement

## Knowledge Base

The knowledge base contains rules about security, backup, and collaboration.

## Sample Rules

- If data sensitivity is high, recommend encrypted restricted storage.
- If backup importance is critical, recommend daily backup with version control.
- If sharing is required and access is frequent, recommend a shared cloud document system.
- Otherwise, recommend normal categorized storage.

## Conclusion

The system gives a basic recommendation using rule-based reasoning.
